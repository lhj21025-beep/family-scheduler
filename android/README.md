# 우리 가족 스케줄러 Android

크롬/WebView를 사용하지 않는 Kotlin 기반 네이티브 Android 앱입니다.
기존 웹앱과 같은 Firebase Authentication, `scheduleDays`, `familyData` 데이터를 공유합니다.

## 포함 기능

- 아빠/엄마/강천 계정 로그인
- 가족 필터가 적용되는 월간 달력과 날짜별 일정
- 일정 등록, 반복 등록, 수정, 삭제
- 시작일~종료일 숙제 묶음 및 반복 횟수 등록
- 숙제 묶음 완료 및 완료 되돌리기
- 오늘 일정 홈 화면 위젯
- 휴대폰/폴드 가변 화면 대응

GitHub Actions의 `Build Android APK` 작업이 디버그 APK를 자동 생성합니다.
